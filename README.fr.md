# Bonjour, moi c'est Illia

**Développeur full-stack d'applications web et de plateformes SaaS.**

[English](README.md) · Français

Je travaille sur les interfaces, les API et les modèles de données, en m'intéressant à leur articulation : qui peut accéder à quelles données, comment une session se termine et comment vérifier qu'un parcours utilisateur fonctionne encore après une modification. Mes projets vont d'une première application Express à une plateforme SaaS multi-tenant, en passant par des projets universitaires en C.
